# 門市排班系統

員工劃休給班、AI 依技能與勞基法自動排班、店長微調發布、即時人效。網頁放在 GitHub Pages，資料存在 Google 試算表。

## 檔案

- `index.html`：排班網頁（放到 GitHub）
- `Code.gs`：Google 試算表後端（貼到 Apps Script）

## 第一次設定

### 1. 建立 Google 試算表後端

1. 新增一份 Google 試算表，例如命名為「中山南西店排班」。
2. 選單「擴充功能 → Apps Script」。
3. 刪掉編輯器裡原本的內容，貼上 `Code.gs` 全部內容。
4. 修改最上面兩組密碼：`STAFF_PIN`（員工）、`MANAGER_PIN`（店長），按儲存。
5. 右上角「部署 → 新增部署作業」→ 齒輪選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
6. 按「部署」，依畫面授權（出現「Google 尚未驗證這個應用程式」時，按「進階 → 前往（不安全）」，這是你自己的程式）。
7. 複製「網頁應用程式網址」，結尾是 `/exec`。

### 2. 把網址填進網頁

打開 `index.html`，找到最上面這一行：

```js
const API_URL = '';
```

把網址貼進引號裡：

```js
const API_URL = 'https://script.google.com/macros/s/xxxxxxxx/exec';
```

### 3. 放上 GitHub Pages

1. 在 GitHub 建一個新的 repository（可設為 Public）。
2. 上傳 `index.html`。
3. Settings → Pages → Source 選「Deploy from a branch」，Branch 選 `main`、資料夾 `/ (root)`，按 Save。
4. 約一分鐘後會出現網址，例如 `https://你的帳號.github.io/repo名稱/`。

### 4. 開始使用

1. 用店長密碼登入，按「建立門市」。
2. 到「門市設定」把員工改成真實名單。
3. 把網址和員工密碼傳給員工，員工登入後選自己的名字填休假。
4. 店長到「排班表」按「AI 自動排班」，確認後「發布班表」。

試算表裡會自動出現「意願 2026-11」「班表 2026-11」工作表，方便列印或給會計看。`_data` 工作表是系統資料，請不要手動修改。

## 之後修改程式

- 改 `Code.gs`：Apps Script 編輯器存檔後，「部署 → 管理部署作業 → 鉛筆圖示 → 版本選『新版本』→ 部署」。網址不會變。
- 改 `index.html`：直接在 GitHub 上傳新檔覆蓋即可。

## 權限

| | 員工密碼 | 店長密碼 |
|---|---|---|
| 填休假、看已發布班表 | ✓ | ✓ |
| 看草稿班表、人效、時薪成本 | | ✓ |
| 排班、發布、修改門市設定 | | ✓ |
